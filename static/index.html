Corrective RAG

Retrieval-Augmented Generation that knows when it's wrong

A modular LangGraph pipeline that grades retrieved documents, routes to web search when context is weak, filters noisy sentences, and only generates when the context can be trusted.

Architecture

The corrective pipeline

Unlike standard RAG which generates blindly from whatever was retrieved, C-RAG scores every chunk, routes to web search when confidence is low, and filters context sentence-by-sentence before generation.

💬
User Query
Natural language question
🔍
Retrieve
FAISS similarity search → top-k chunks
⚖️
Score Each Document
LLM scores every chunk 0.0 → 1.0 · thresholds: 0.3 / 0.7
VERDICT → ROUTING DECISION
CORRECT
any score > 0.7
skip web search
use local docs only
AMBIGUOUS
mixed scores
rewrite query →
web search
local + web docs
INCORRECT
all scores < 0.3
rewrite query →
web search
web docs only
✂️
Sentence-Level Refinement
Decompose context → LLM filter keeps / drops each sentence
✨
Generate
Answer grounded in verified, filtered context only
Features

What makes C-RAG different

Every stage between retrieval and generation has a job — nothing reaches the LLM unchecked.

⚖️
Score-Based Grading
Each retrieved chunk gets a relevance score in [0, 1]. Thresholds at 0.3 and 0.7 determine the routing verdict — no binary pass/fail.
🌐
Conditional Web Fallback
Tavily web search is only triggered when local documents are weak or irrelevant. CORRECT verdicts skip the web entirely for speed.
✂️
Sentence-Level Filtering
Context is decomposed to individual sentences. An LLM judge filters each one — only sentences that directly answer the question survive.
🔀
LangGraph State Machine
Built on LangGraph with typed state, conditional edges, and explicit routing. Every decision point is inspectable and auditable.
🦙
Fully Local by Default
Runs on Ollama (llama3.1 + embeddinggemma) — no OpenAI key needed. Swap any model by changing one line.
🔌
Modular Nodes
Each pipeline stage is a standalone function. Swap the retriever, embeddings, LLM, or web search tool without touching the graph.
Getting Started

Up and running in minutes

You need Ollama running locally and a free Tavily API key. Everything else is Python.

1
Clone and install
git clone https://github.com/Darsh-Nandu/Corrective-Retrieval-Augmented-Generation.git
cd Corrective-Retrieval-Augmented-Generation
python -m venv crag_venv && source crag_venv/bin/activate
pip install -r requirements.txt
2
Install Ollama models
Download Ollama, then pull the required models:
ollama pull llama3.1
ollama pull embeddinggemma:latest
3
Add your Tavily API key
Get a free key at tavily.com — used for web search fallback.
cp .env.example .env
# Edit .env and add your key:
TAVILY_API_KEY=tvly-your-key-here
4
Add your documents and run
Drop PDFs into the documents/ folder, then ask a question:
python main.py "What is the difference between batch and layer normalization?"

# Or with verbose intermediate state:
python main.py "Explain attention mechanisms" --verbose
